# Reeside open letter: sign-up page (TEST)

Test copy of the campaign's open-letter sign-up page. Signers see their personal share link
the moment they sign; the answers go to the campaign's Apps Script endpoint, which records
them in the campaign's Google Sheet and sends the confirmation email.

- Page: https://debate.reesideforcongress.com/
- Wording and settings: `assets/js/content.js` (keep the letter and consent text identical to the Sheet's CONFIG tab).
- Styling follows reesideforcongress.com. Fonts are self-hosted (Montserrat, Oswald; SIL Open Font License); images are the campaign's own.
- No cookies, no analytics. The page is marked noindex while it is a test.
